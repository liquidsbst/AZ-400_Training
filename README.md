# AZ-400 Training

Materiały szkoleniowe przygotowujące do egzaminu **AZ-400: Designing and Implementing Microsoft DevOps Solutions**.

## Zawartość repozytorium

- [PROGRAM.md](PROGRAM.md) — pełny program szkolenia, podzielony na ścieżki szkoleniowe i moduły.

## Zakres tematyczny

Szkolenie obejmuje 8 ścieżek szkoleniowych dotyczących wdrażania praktyk DevOps w przedsiębiorstwie, w tym m.in.:

- wdrażanie metodyk DevOps i pracę z Agile,
- integrację ciągłą (CI) z Azure Pipelines i GitHub Actions,
- strategie wydawnicze i ciągłe wdrażanie (CD),
- infrastrukturę jako kod (IaC) na platformie Azure,
- bezpieczeństwo i zgodność kodu,
- zarządzanie zależnościami,
- continuous feedback.

Szczegółowy rozkład modułów znajduje się w [PROGRAM.md](PROGRAM.md).
